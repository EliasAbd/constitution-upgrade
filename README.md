# Constitution Upgrade Contract

A governance-controlled contract that manages upgrades to a protocol’s
core ruleset (constitution) through transparent on-chain processes.

## Key Functions
- `propose-amendment` — Submit a constitution change proposal
- `approve-amendment` — Record governance approval
- `activate-amendment` — Apply approved constitution changes
- `get-amendment` — View amendment details and status
- `is-active` — Check if a constitution version is in effect

Designed for DAOs and protocols requiring structured evolution of
foundational governance rules.
